# Changelog

Tagged releases identify the exact toolkit and standalone skill to install. Version 0.2.0 is the first tagged release; earlier entries identify historical snapshots by commit. Installation does not automatically update copied skills or adapted project documents.

## 0.2.0 — 2026-09-08

- Clarify public/private risk disclosure, command targets and side effects, isolated recovery, and access/ownership handover without authorizing operational changes.
- Add optional, source-checked Vercel/Supabase/Neon guidance, including preview data, recovery exclusions, and plan-dependent limits.
- Add fictional checkpoint/decision examples, default locations for supporting records, placeholder cleanup, and explicit receiving-harness discovery checks.
- Improve pause/expiry, monitoring, and ownership prompts; make NOW's length an upper guide and keep ADR status in its canonical record.
- Keep repo-link adoption simple, pin installation examples to this release, and explain checkout locations and deliberate upgrades.
- Add reproducible documentation/package checks and CI; report all asset drift and handle conflicting paths without automatic deletion.

Validation scope and commands are recorded in [SKILL-VALIDATION.md](SKILL-VALIDATION.md). This release does not configure an adopter's infrastructure or certify their production readiness.

# Maintaining Vibe Code Docs Stack

This repository contains a documentation playbook, prompts, templates, and maintainer checks. Do not scaffold application documentation into this toolkit. The instruction files under starter-kit and skills/vibe-code-docs-stack/assets/templates are sample material, including their AGENTS.md and CLAUDE.md files; do not apply them as maintainer instructions.

Read [README.md](README.md), then [CONTRIBUTING.md](CONTRIBUTING.md) for canonical contributor rules, validation commands, and source ownership. Inspect actual Git state and read only task-relevant source documents before editing. Preserve other contributors' work.

The root [CLAUDE.md](CLAUDE.md) imports this maintainer contract. Keep the rules here and in CONTRIBUTING, rather than duplicating them in harness adapters.

Use the [required checks](CONTRIBUTING.md#checks) before finishing. Report passed, failed, and not-run results with scope and evidence; documentation and package checks do not establish target-application or live harness readiness.
